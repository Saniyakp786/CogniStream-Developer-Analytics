# Team Contribution Guidelines

## Project Workflow

1. Understand the existing project structure before making changes.
2. Work on your assigned task.
3. Keep project files organized.
4. Test your changes before committing.
5. Write a clear commit message describing the actual changes.
6. Review changes before pushing them to GitHub.
7. Coordinate with team members to avoid conflicts.

## Git Best Practices

- Do not commit API keys, passwords, or secret files.
- Avoid modifying another team member's work without discussion.
- Keep commits small and focused on one task.
- Pull the latest changes before starting new work.

## Team Collaboration

Communicate completed tasks and pending work with the team leader to keep project development organized.
