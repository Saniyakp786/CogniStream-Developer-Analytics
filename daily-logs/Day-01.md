# Day 1 – CogniStream Project Initialization

## Project Title
**CogniStream: Developer Flow-State & Cognitive Load Analytics**

## Objective
To initialize the CogniStream project and define its purpose, problem statement, objectives, and initial technology stack.

## Work Completed

1. Created the initial CogniStream project structure.
2. Defined the project overview.
3. Identified the problem statement.
4. Listed the main project objectives.
5. Selected the initial technology stack.
6. Identified the data sources required for developer activity analytics.
7. Created the initial project documentation.

## Problem Statement

Traditional engineering productivity metrics, such as lines of code and tickets closed, often overlook interruptions and the difficulty of maintaining focused work.

CogniStream aims to analyze developer focus sessions, interruptions, context switching, and cognitive workload.

## Project Objectives

- Analyze developer activity events.
- Identify uninterrupted flow sessions.
- Measure interruptions and context switching.
- Calculate flow and productivity metrics.
- Visualize insights through an interactive dashboard.

## Initial Technology Stack

- Apache Airflow – Workflow orchestration
- ClickHouse – Analytical database
- Python and Polars – Data processing
- FastAPI – Backend API
- React and Tremor.js – Frontend dashboard

## Data Sources

Synthetic or authorized event data representing:
- GitHub
- Slack
- Jira
- IDE activity

## Outcome

The initial project structure and documentation were established. The project concept, problem statement, objectives, and technology stack were defined.
