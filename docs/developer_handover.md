# CogniStream Developer Handover Guide

## Project Handover

This guide helps team members understand the project before continuing development.

## Important Handover Information

- Review the main README before starting.
- Understand the existing project folder structure.
- Check the required Python dependencies.
- Review the environment configuration.
- Understand the dashboard and RAG modules.
- Review existing documentation and tests.

## Before Making Changes

1. Confirm the assigned task.
2. Identify the relevant project files.
3. Understand existing functionality.
4. Avoid modifying unrelated files.
5. Test changes before committing.

## Team Communication

- Share completed work with the team.
- Document important updates.
- Report unresolved issues.
- Coordinate before modifying shared files.
