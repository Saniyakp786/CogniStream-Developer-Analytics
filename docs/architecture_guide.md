# CogniStream Architecture Guide

## Project Architecture

CogniStream is organized into separate modules to make development and maintenance easier.

## Main Components

### 1. Streamlit Application
The main application provides the user interface.

### 2. Data Processing
The data processing modules handle cleaning, analysis, and KPI calculations.

### 3. Dashboard
The dashboard module presents analytics through interactive visualizations.

### 4. RAG System
The RAG modules support document ingestion, retrieval, and contextual question answering.

### 5. Power BI
The Power BI folder contains dashboard resources, measures, and theme configuration.

### 6. Tests
The tests folder contains automated tests for selected project components.

## Architecture Benefits

- Separation of responsibilities
- Easier maintenance
- Reusable components
- Better project organization
