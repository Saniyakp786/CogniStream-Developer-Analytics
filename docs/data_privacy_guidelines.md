# CogniStream Data Privacy Guidelines

## Data Protection

- Do not include personal or confidential information in public datasets.
- Review uploaded documents before processing.
- Avoid sharing sensitive developer information.
- Use sample data when demonstrating project functionality.

## API Key Protection

- Never publish API keys or passwords.
- Keep sensitive configuration files outside Git commits.
- Use environment variables for credentials.

## Data Sharing

- Share project datasets only with authorized team members.
- Review files before uploading them to GitHub.
- Remove sensitive information before publishing reports.

## Responsible Data Usage

- Use data only for the intended project purpose.
- Verify information before presenting analytical results.
- Follow applicable privacy and data protection requirements.
