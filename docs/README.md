\# CogniStream – Cognitive Load Analysis



\## Overview

The Cognitive Load Analysis page is designed to understand the mental workload experienced by developers during their coding sessions.



It analyzes how cognitive load levels are associated with interruptions, context switching, and task complexity.



\## Key Features



\### 1. Cognitive Load Distribution

Displays the distribution of developer sessions across Low, Medium, and High cognitive load levels.



\### 2. Interruptions Analysis

Analyzes interruptions across different cognitive load categories to understand their relationship with developer focus.



\### 3. Context Switching Analysis

Compares context switching across cognitive load levels to identify possible workflow disruptions.



\### 4. Task Complexity Analysis

Examines the relationship between task complexity and cognitive load levels.



\### 5. Cognitive Load Summary

Provides summarized metrics grouped by cognitive load category.



\## Technologies Used

\- Python

\- Pandas

\- Plotly

\- Git and GitHub



\## Project Files

\- `dashboard/views.py` – Cognitive Load dashboard implementation.

\## Expected Outcome

The analysis helps identify patterns in developer cognitive workload and understand how interruptions, context switching, and task complexity relate to productivity and flow state.
