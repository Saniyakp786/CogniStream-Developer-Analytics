# CogniStream Installation Guide

## Prerequisites

- Python installed on your system.
- Git installed on your system.
- VS Code or another code editor.

## Installation Steps

1. Clone or download the CogniStream repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install dependencies using `requirements.txt`.
5. Configure the required environment variables using your local configuration.
6. Follow the application run command provided in the main README.

## Important Notes

- Do not share API keys or passwords.
- Keep your dependencies updated.
- Use the project's documented Python version and setup instructions.
