# CogniStream Troubleshooting Guide

## 1. Application Does Not Start
- Confirm that Python is installed.
- Open the terminal in the project folder.
- Install the dependencies listed in `requirements.txt`.
- Follow the run instructions in the main README file.

## 2. Missing Environment Variables
- Check the `.env.example` file for the required variable names.
- Configure your own API key locally if the project requires one.
- Never upload real API keys or passwords to GitHub.

## 3. Dependency Errors
- Activate the correct Python virtual environment.
- Install the project's required packages.
- Check the error message to identify any missing dependency.

## 4. Dashboard or Charts Do Not Load
- Check that the required dataset files exist.
- Confirm that the dataset paths are correct.
- Review the terminal output for errors.

## 5. Still Having Issues?
Record the error message and the steps that caused it before asking the team for help.
