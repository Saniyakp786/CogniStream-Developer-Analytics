# CogniStream Dashboard User Guide

## Dashboard Overview

The dashboard provides visual insights into developer activity and productivity.

## How to Use the Dashboard

1. Open the CogniStream application.
2. Navigate to the dashboard section.
3. Review the available KPI cards.
4. Explore charts to understand productivity patterns.
5. Apply available filters to analyze specific records.
6. Compare results across different developer or work categories.

## Dashboard Interpretation

- KPI cards provide summarized metrics.
- Charts help identify trends and comparisons.
- Filters allow users to focus on selected data.
- Interpret results using the selected filters and dataset context.

## Important Note

Dashboard features and filters may vary depending on the available project configuration.
