# CogniStream Project Glossary

## Technical Terms

**RAG (Retrieval-Augmented Generation):** A technique that retrieves relevant information before generating an answer.

**Embedding:** A numerical representation of text used for similarity search.

**Vector Database:** A system used to store and search vector embeddings.

**Data Cleaning:** The process of identifying and handling missing, duplicate, or inconsistent data.

**KPI (Key Performance Indicator):** A measurable value used to track performance.

**Dashboard:** A visual interface that presents important information and analytics.

**Streamlit:** A Python framework used to build interactive data applications.

**Power BI:** A business intelligence tool used to create reports and dashboards.

## Purpose

This glossary helps team members understand the technical terminology used throughout the CogniStream project.
