# Frequently Asked Questions (FAQ)

## 1. What is CogniStream?
CogniStream is a developer analytics project that combines an interactive dashboard with RAG-based question answering.

## 2. What is RAG?
RAG stands for Retrieval-Augmented Generation. It retrieves relevant information and uses it to help generate answers.

## 3. What is the purpose of the dashboard?
The dashboard presents developer productivity and related analytics through visualizations and key metrics.

## 4. Where are the project datasets stored?
The main datasets are stored in the `data/` directory.

## 5. Where can I find project documentation?
Project documentation is available in the `docs/` directory and the main `README.md` file.

## 6. Where can I find the dependencies?
The main dependencies are listed in `requirements.txt`.
