# Day 01 - CogniStream Project Initialization

## Project Name
CogniStream: Developer Flow-State & Cognitive Load Analytics

## Objective
Analyze developer productivity, focus, cognitive load, interruptions, and context switching using data analytics and visualization.

## Main Components
1. Data collection and preprocessing
2. Exploratory data analysis
3. Productivity KPI calculations
4. Interactive Streamlit dashboard
5. Power BI reporting support
6. RAG-based AI assistant

## Technology Stack
- Python
- Pandas and NumPy
- Streamlit
- Power BI
- Git and GitHub

## Expected Outcome
Build an analytics application that helps users understand developer work patterns and identify factors associated with productivity and interruptions.
