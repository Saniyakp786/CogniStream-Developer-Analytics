# CogniStream Analytics Reporting Guide

## Purpose

This guide explains how to present analytical findings from the CogniStream dashboard.

## Reporting Process

1. Select the relevant dataset and filters.
2. Review the available KPI cards.
3. Examine productivity and focus-related charts.
4. Compare different work modes and categories.
5. Identify important patterns in the results.
6. Record observations with supporting metrics.

## Reporting Best Practices

- Include the reporting period.
- Mention the filters used.
- Use accurate metric values.
- Avoid unsupported conclusions.
- Distinguish correlation from causation.
- Clearly mention dataset limitations.

## Conclusion

A good analytics report should communicate findings clearly and support conclusions with verified data.
