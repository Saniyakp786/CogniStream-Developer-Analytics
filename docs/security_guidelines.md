# CogniStream Security Guidelines

## Protect Sensitive Information

- Never upload API keys or passwords to GitHub.
- Keep secret configuration files out of version control.
- Use environment variables for sensitive credentials.
- Share access only with authorized team members.

## Repository Safety

- Review files before committing.
- Check that datasets do not contain private information.
- Avoid sharing confidential project information publicly.
- Review changes before pushing them to the remote repository.

## Team Responsibilities

Every team member should follow these security practices while developing and maintaining CogniStream.
