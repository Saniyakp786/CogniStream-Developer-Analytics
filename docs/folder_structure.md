# CogniStream Project Structure

This document explains the main folders and files of the project.

## Main Files and Folders

- `app.py` – Main Streamlit application.
- `dashboard/` – Dashboard charts, views, and styling.
- `rag/` – RAG pipeline, ingestion, retrieval, and assistant modules.
- `data/` – Project datasets.
- `docs/` – Project documentation.
- `reports/` – Analysis reports and generated charts.
- `src/` – Data processing, cleaning, and KPI modules.
- `tests/` – Project testing files.
- `powerbi/` – Power BI-related resources.
- `requirements.txt` – Main Python dependencies.
- `README.md` – Project introduction and instructions.

## Purpose

The project structure separates dashboard development, RAG functionality, data processing, reports, and documentation to make the project easier to maintain.
