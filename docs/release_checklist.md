# CogniStream Release Checklist

## Before Release

- [ ] Verify that the application starts successfully.
- [ ] Check dashboard navigation.
- [ ] Verify that available charts load correctly.
- [ ] Test document ingestion and retrieval.
- [ ] Check environment configuration.
- [ ] Run the available project tests.
- [ ] Review error messages and application logs.

## Documentation Review

- [ ] Update README instructions.
- [ ] Verify installation steps.
- [ ] Review project dependencies.
- [ ] Check that no API keys or passwords are included.

## Final Review

- [ ] Review all modified files.
- [ ] Confirm that changes are committed to the correct branch.
- [ ] Inform team members about the release.
